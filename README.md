# Goose Patrol

## Running the game

cd goose-patrol

mac:
```
export JAVA_HOME=$(/usr/libexec/java_home -v 17)
./gradlew run
```

linux:
```
./gradlew run
```

windows:
```
gradlew.bat run
```

## Controls

- click START to play
- WASD or arrows to walk
- SPACE to pause
- 1 and 2 to select an inventory item
- E consume
- R reset
